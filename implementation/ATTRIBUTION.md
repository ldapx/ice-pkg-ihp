# Implementation data attribution

The files under `implementation/common` and `implementation/stacks` are derived
from the IHP SG13G2 open-source PDK.

- Project: IHP-Open-PDK
- Source: https://github.com/IHP-GmbH/IHP-Open-PDK
- Standard-cell release: SG13G2 rev0.1.4 (12 Jan 2026)
- License: Apache-2.0

The `implementation/common/layer.map` file is the IHP KLayout DEF-to-GDS layer map.

The physical data is bundled with this ICE package so the digital
implementation flow does not depend on an external PDK installation or Volare.
